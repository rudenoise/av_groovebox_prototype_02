# AV Groovebox Prototype 02

A prototype tool for creating audio/visual output by reacting to audio and MIDI inputs.

## Setup

```sh
npm install
```

Requires a MIDI controller connected to the system.

## Usage

```sh
npm start
```

Connect a MIDI controller. MIDI note/CC messages trigger video playback, image swaps, and visual filters in real time.

## Development

```sh
npm run watch      # auto-restart on file changes (requires entr)
npm run format     # lint and format
```
